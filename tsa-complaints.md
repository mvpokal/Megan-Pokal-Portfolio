# TSA Complaints Analysis

## Overview
This project analyzes TSA traveler complaint data to identify trends in passenger concerns across airports, complaint categories, and time periods. The goal is to better understand operational issues and improve traveler experience insights.

---

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib / Seaborn
- Jupyter Notebook

---

## Key Files
- TSA Complaints Code.ipynb – Data cleaning and analysis notebook  
- TSA Complaints Paper.pdf – Written analysis report  
- complaints_by_airport.csv – Aggregated airport-level complaint data  
- complaints_by_category.csv – Complaint categorization dataset  
- iata_icao.csv – Airport code reference data  

---

## Key Insights
- Identified top airports with highest complaint volumes  
- Analyzed most common complaint categories  
- Explored patterns across geography and airport size  
- Highlighted operational areas needing improvement
