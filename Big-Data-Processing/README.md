# Big Data Processing with Hadoop, Apache NiFi, Apache Solr, and HBase

## Project Overview
This project demonstrates the use of big data technologies to ingest, store, process, and analyze large datasets using Hadoop, Apache NiFi, Apache Solr, and HBase. The goal was to understand how distributed systems and NoSQL databases work together to handle large-scale data workflows efficiently.

## Objectives
- Understand core big data processing concepts
- Work with distributed storage using Hadoop (HDFS)
- Build automated data pipelines using Apache NiFi
- Implement search and indexing using Apache Solr
- Explore NoSQL database storage using HBase

## Tools & Technologies
- Hadoop (HDFS, distributed storage)
- Apache NiFi (data ingestion and pipelines)
- Apache Solr (search and indexing)
- HBase (NoSQL database)
- Linux / Terminal

## Project Structure
- **Hadoop**: Distributed storage and file management using HDFS
- **Apache NiFi**: Automated data ingestion and pipeline workflows
- **Apache Solr**: Data indexing and fast search capabilities
- **HBase**: NoSQL database for real-time read/write access to large datasets

## Key Steps
1. Set up and configured big data tools in a local environment  
2. Stored and managed data using Hadoop Distributed File System (HDFS)  
3. Built data pipelines for ingestion and transformation using Apache NiFi  
4. Indexed and queried data using Apache Solr  
5. Stored and retrieved structured data using HBase  
6. Validated outputs through terminal commands and system logs  

## Results & Insights
- Demonstrated how distributed systems handle large-scale data efficiently  
- Built automated pipelines for real-time and batch data processing  
- Improved data retrieval speed using indexing with Solr  
- Gained experience with NoSQL data storage using HBase  

## Challenges
- Complex setup and configuration of multiple big data tools  
- Managing system dependencies and environment variables  
- Understanding how tools integrate within a data pipeline  

## Key Takeaways
This project provided hands-on experience with the big data ecosystem and showed how tools like Hadoop, NiFi, Solr, and HBase work together to support scalable data processing, storage, and retrieval in real-world applications.
